    ![Изображение](screenshot/Part_8.2.png "Обновляем системные пакеты")

- Отображение наличия процесса. ps - выводит сведения о процессах в статическом виде,
-e - позволяет выбрать все процессы, | grep sshd - поиск по выводу

    ![Изображение](screenshot/Part_8.3.png "Отображение наличия процесса")

- Перезагрузка системы - reboot
- Вывод команды netstat -tan

    ![Изображение](screenshot/Part_8.4.png "Обновляем системные пакеты")

    -tan:

        1) -a - Показывать состояние всех сокетов; обычно сокеты, используемые серверными процессами, не показываются.

        2) -n - Показывать сетевые адреса как числа. netstat обычно показывает адреса как символы.

        3) -t - Отображать TCP подключения

        4) Proto - Содержит тип протокола

        5) Recv-Q - Счётчик байтов не скопированных программой пользователя из этого сокета.

        6) Send-Q - Счётчик байтов, не подтверждённых удалённым узлом.

        7) Local Address - Адрес и номер порта локального конца сокета.

        8) Foreign Address - Адрес и номер порта удалённого конца сокета.

        9) State - Состояние сокета.

        10) LISTEN Сокет ожидает входящих подключений.

        11) SYN_SENT Сокет, находящийся в режиме активной попытки установки подключения.

        12) 0.0.0.0 - это немаршрутизируемый адрес IPv4, который используется в качестве адреса по умолчанию или адреса-заполнителя.
